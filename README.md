# Week 6 Folder Maker App

## Purpose
My app creates the chance for the user to be able to track the anime they are watching or have watched, what episode they are on, and the ability to rate the anime.

## How To Run
VB.NET console app will display a menu with options such as adding an anime, viewing saved anime infomation, updating watch status, and exiting the program.

## Folder Structure Created
AnimeWatchList,ReadME.txt,AnimeInfo.txt, and Notes.txt

## Story to App Connection
I watch multiple animes at a time and get confused where I left off and if i would return to rewatch the anime.
